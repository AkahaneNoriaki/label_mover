# Label Mover

QGISの印刷レイアウト上で、ベクターレイヤーのラベルをテキストアイテムとして追加・編集できるプラグインです。

## 概要

QGISの標準ラベル機能では、印刷レイアウト上でラベルの位置を自由に移動することができません。このプラグインは、ラベルをレイアウト上のテキストアイテムとして追加することで、ドラッグによる自由な位置調整を可能にします。

## 主な機能

- **印刷範囲内のラベルを一括追加**：アクティブレイヤーの印刷範囲内フィーチャのラベルを、レイアウト上にテキストアイテムとして一括追加します。数式ラベルにも対応しています。
- **テキストスタイルを一括設定**：フォントサイズ・色・太字・斜体・バッファー（ハロー）を全テキストアイテムに一括適用します。
- **重なり確認**：重なっているテキストアイテムを赤色でハイライトして視覚的に確認できます。
- **次のラベルへ移動**：レイアウト上のテキストアイテムを順番に選択して移動できます。
- **クリア**：追加したテキストアイテムを全削除し、元のラベルを再表示します。
- **元のラベルを再表示**：非表示にした元のラベルをもとに戻します。
- **レイアウト画面ツールバー対応**：印刷レイアウト画面を開くと、ツールバーに全機能のボタンが自動追加されます。

## インストール方法

1. このリポジトリをZIPでダウンロードします。
2. ZIPを解凍し、`label_mover` フォルダをQGISのプラグインフォルダにコピーします。
   - Windowsの場合：`C:\Users\（ユーザー名）\AppData\Roaming\QGIS\QGIS3\profiles\default\python\plugins\`
   - Mac/Linuxの場合：`~/.local/share/QGIS/QGIS3/profiles/default/python/plugins/`
3. QGISを再起動します。
4. メニューの「プラグイン」→「プラグインの管理とインストール」→「インストール済み」タブで `Label Mover` にチェックを入れます。

## 使い方

### 基本的な流れ

1. QGISでベクターレイヤーを読み込み、ラベル設定をしておきます。
2. 印刷レイアウトを作成・開き、地図アイテムの表示範囲を設定します。
3. レイヤーパネルでアクティブレイヤーを選択します。
4. メニュー「プラグイン」→「Label Mover」→「印刷範囲内のラベルを一括追加」を実行します（レイアウト画面のツールバーからも操作できます）。
5. レイアウト上に追加されたテキストアイテムをドラッグして位置を調整します。
6. 「テキストスタイルを一括設定」でフォントやバッファーを設定します。
7. 「重なり確認」で重なりをチェックし、必要に応じて移動します。

### メニュー・ツールバーの機能

| 機能 | 説明 |
|------|------|
| 印刷範囲内のラベルを一括追加 | アクティブレイヤーの印刷範囲内ラベルを追加 |
| テキストスタイルを一括設定 | フォント・色・バッファーを一括設定 |
| クリア | テキストアイテムを全削除・元ラベルを再表示 |
| 元のラベルを再表示 | 非表示にした元ラベルを復元 |
| ▶ 次のラベルへ | テキストアイテムを順番に選択 |
| ⚠ 重なり確認 | 重なりを検出して赤くハイライト |

## 動作環境

- QGIS 3.28 以上
- Windows / Mac / Linux

## 注意事項

- 対象はアクティブレイヤーのみです。操作前にレイヤーパネルで対象レイヤーを選択してください。
- ラベル設定（フィールド名または数式）がないレイヤーは対象外です。
- NULL値のラベルは自動的にスキップされます。
